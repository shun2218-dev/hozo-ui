# 学習ログの下書きを作る

## 手順

1. `LEARNING_LOG.md` を読み、次の ID とフォーマットを確認する
2. 直近の会話から、今回扱ったトピックと詰まった箇所を拾う
3. **下書きを提示する。ただし以下の欄は空欄のまま渡す**
   - 到達（◎/○/△/✕）
   - 一言で説明すると
4. 「この2つは自分で埋めてください」と伝える
5. 本人が埋めたら、`LEARNING_LOG.md` に追記し、索引の表も更新する

## 厳守

- 承認前に `LEARNING_LOG.md` へ書き込まない
- 「一言で説明すると」を代筆しない。ここが書けないなら理解していないというのがこの欄の役割
- 到達レベルを勝手に判定しない。本人の申告を使う
- 答えを見た回は必ず ✕ として提案する
- 未解決の疑問が残っていれば「積み残し」への追加も提案する
