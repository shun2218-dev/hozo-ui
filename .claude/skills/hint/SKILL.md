# ヒントを出す

対象トピック: $ARGUMENTS

## 手順

1. `LEARNING_LOG.md` を読む
2. 対象トピック、および関連する型テクニックの記録があるか探す
3. `CLAUDE.md` の基準でヒントレベルを判定する
   - 記録なし → **Lv3**
   - ○ または △ が 1 回 → **Lv2**
   - ○ 以上が 2 回、または ◎ → **Lv1**
   - ✕ のみ → **Lv3 据え置き**
4. **判定結果と根拠（ログの ID）を最初に宣言する**
5. そのレベルのヒントを出す

## 厳守

- 実装コードを書かない。型定義の完成形も出さない
- Lv3 でも「形」までにとどめる（中身は `___` で空欄）
- 「一般的にはこう書きます」という逃げ道を使わない
- 関連しそうな既存の記録があれば、そのIDを示して自分で読み返すよう促す

## 出力の形

```
判定: Lv2（L-002 に polymorphic の記録あり、到達 ○）

<レベルに応じたヒント>

確認方法: <書けたらどう検証するか>
```
